# guides/ - 무료 가이드 및 참고 문서

이 폴더에는 강의에서 제공하는 무료 가이드와 트러블슈팅 문서가 들어 있습니다.

## 폴더 구조

```
guides/
├─ section01-lecture01/    # 온보딩 가이드
│  └─ onboarding/          # 환경 설정 가이드
│     ├─ 01-openclaw-wsl2-docker-gemini-dashboard-setup.md
│     └─ 02-telegram-setup-pairing-guide.md
├─ troubleshooting/       # 트러블슈팅
│  ├─ 01-troubleshooting-텔레그램 연동 오류.md
│  └─ 02-troubleshooting-제미나이 모델 과부하 오류.md
└─ README.md              # 본 파일
```

## 사용 시점

- **강의 시작 전**: 온보딩 가이드로 환경 설정
- **실습 중 문제 발생 시**: 트러블슈팅 문서 참조
- **설정 확인 필요 시**: 관련 가이드 재확인

> 💡 1·2부를 미수강한 경우, section01-lecture01의 온보딩 가이드를 먼저 참조하세요.

---

## 활용 팁

- 강의와 함께 실습을 진행할 때, 이 폴더의 문서는 **“옆에 두고 수시로 펼쳐보는 참고서”**라고 생각하시면 편합니다.
- 설치/연동 관련 내용은 영상만 보고 지나가기보다, 최소 한 번은 PDF/MD 문서를 끝까지 읽어 보시는 것을 추천드립니다.
- 공통으로 자주 나오는 문제는 `troubleshooting/`에 계속해서 추가·보완될 수 있으니, 실습 중 막히면 가장 먼저 확인해 주세요.
