# codes/ - 실습 코드 및 설정 파일

이 폴더에는 인프런 각 수업별 실습에서 사용하는 코드와 설정 파일이 들어 있습니다.

## 폴더 구조

```
codes/
├─ section01-lecture02/    # 섹션 1 > 수업 2: OpenClaw 화면·개념 5분 정리
├─ section03-lecture05/    # 섹션 3 > 수업 5: Planner/Editor 에이전트 만들기 & 워크스페이스 분리
├─ section03-lecture07/    # 섹션 3 > 수업 7: 텔레그램 토픽에 Planner/Editor 연결 및 라우팅
├─ section04-lecture08/    # 섹션 4 > 수업 8: 역할 경계와 변경 승인 흐름이 있는 사람 매개 협업 실습
└─ README.md               # 본 파일
```

## 사용 방법

1. **인프런에서 현재 듣고 있는 섹션/수업 번호**를 확인합니다.
2. 해당하는 `sectionXX-lectureYY/` 폴더를 엽니다.
3. 강의에서 설명하는 핵심 설정을 따라 수정합니다.
