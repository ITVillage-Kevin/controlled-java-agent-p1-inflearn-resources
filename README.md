# OpenClaw.ai 기초 2.5부 수강생 리소스

이 저장소는 **[기초 2.5부] OpenClaw.AI 마스터 클래스: 멀티 에이전트 팀과 텔레그램 포럼 라우팅 기초** 강의에서 사용하는 소스코드, 설정 파일, 실습 데이터, 슬라이드, 가이드 문서를 모아둔 공간입니다.  
1·2부에서 만든 “내 PC 속 AI 비서 + 텔레그램 원격 제어 환경”을 바탕으로,  
2.5부에서는 **멀티 에이전트 팀(planner/editor) 구성과 텔레그램 포럼 토픽별 라우팅, 워크스페이스 분리**를 실습하는 데 필요한 자료를 제공합니다.

---

## 저장소 구조

```bash
.
├─ codes/         # 수업별 실습에 필요한 코드 및 설정 파일
├─ guides/        # 무료 가이드 및 참고 문서
├─ results/       # 수업별 실습으로 자동 생성되는 결과 데이터
└─ slides/        # 강의 슬라이드 PDF
```

---

## 폴더별 안내

`codes/`  
- 각 수업별 실습에서 사용하는 파일들이 들어 있습니다.

- 예시:

  - `agents.list`에 `assistant / content-planner / content-editor`를 추가한 워크스페이스 경로가 반영된 `openclaw.json`

- 인프런에서 현재 듣고 있는 섹션/수업 번호에 맞는 폴더를 찾아, 그 안의 파일을 참고해서 실습을 진행합니다.

`guides/`  
- **[무료 가이드]**에 해당하는 문서를 모아둔 폴더입니다.

- 예시:

  - 2.5부 합류용 온보딩 가이드(1·2부 미수강자를 위한 셋업 가이드)
  - 강의를 진행하면서 발생할 수 있는 트러블슈팅 내용

`results/`  
- 실습에서 에이전트의 동작으로 자동으로 생성되는 결과물이 들어 있습니다.

- 예시:

  - 사람 복붙 기반 planner↔editor 협업 실습을 마친 후의 결과 문서

`slides/`  
- 각 수업에서 사용한 **슬라이드 PDF**가 들어 있습니다.
- 파일명은 1·2부와 유사한 규칙(예: `basic-p2.5-sectionXX-lectureYY.pdf`)을 따릅니다.
- 영상에서 봤던 화면을 정지 없이 다시 보고 싶을 때,  
  또는 에이전트/채널 구조 다이어그램과 프롬프트 예시를 확대해서 보고 싶을 때 활용하세요.

---

## 사용 방법

1. 인프런에서 해당 수업 영상을 시청합니다.

2. 현재 섹션/수업 번호에 맞는 `codes/sectionXX-lectureYY/`를 열고, `README.md`를 읽은 뒤 안내된 파일들을 작업 폴더로 복사합니다.

3. 멀티 에이전트 정의, 워크스페이스 분리, 텔레그램 포럼 라우팅 등 **이번 수업에서 다루는 핵심 설정**을 강의 순서에 맞춰 수정합니다.

4. 실습 중 막히면 `guides/`의 온보딩 가이드, 텔레그램 페어링 연결 가이드, 트러블슈팅 문서를 함고합니다.

5. 수업에서 본 슬라이드는 `slides/`에서 확인할 수 있습니다.

---

## 주의사항

- 이 저장소에는 **실제 Gemini API 키, 텔레그램 봇 토큰** 등은 절대 포함되어 있지 않습니다.  
  강의에서는 민감한 값은 항상 **환경변수와 로컬 설정 파일**로 관리합니다.
